# Nexus Mods

DewDrop works with [Nexus Mods](https://www.nexusmods.com/stardewvalley), where most Stardew Valley mods live. You can browse and search Nexus Mods on the **Browse** tab without an account. To download and install mods from inside the game, you log in with your Nexus Mods account. A free account is enough.

What you can do depends on your account:

| | Not logged in | Free account | Premium account |
| --- | --- | --- | --- |
| Browse and search mods | Yes | Yes | Yes |
| See which of your mods have updates | Yes | Yes | Yes |
| Install a file from a mod's page | No | Yes, through the website's **Slow download** button (Windows only) | Yes, straight into the game |
| Install an update with the **Update to** button | No | Yes, through the website (Windows only) | Yes, straight into the game |
