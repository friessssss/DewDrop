# Using DewDrop

Everything in DewDrop happens in one menu: click **Mods** on Stardew Valley's title screen. These guides go through it tab by tab. If you haven't installed DewDrop yet, start with the [Quick start](../quick-start.md).

* <img src="../.gitbook/assets/icons/window.png" alt="" data-size="line"> [The DewDrop menu](the-menu.md): open and close it, read the bottom bar, and use it with a mouse, keyboard, controller or Steam Deck.
* <img src="../.gitbook/assets/icons/installed.png" alt="" data-size="line"> [Managing your mods](installed.md): turn mods on and off, find problems, and uninstall mods on the **Installed** tab.
* <img src="../.gitbook/assets/icons/browse.png" alt="" data-size="line"> [Browsing Nexus Mods](browse.md): search and sort mods on the **Browse** tab, and see which ones you already have.
* <img src="../.gitbook/assets/icons/puzzle.png" alt="" data-size="line"> [A mod's page and installing files](mod-page.md): pick a file and install it, or uninstall the mod.
* <img src="../.gitbook/assets/icons/check.png" alt="" data-size="line"> [Updating mods](updating-mods.md): how DewDrop finds updates and installs them.
* <img src="../.gitbook/assets/icons/profiles.png" alt="" data-size="line"> [Profiles](profiles.md): keep different sets of mods and switch between them.
* <img src="../.gitbook/assets/icons/downloads.png" alt="" data-size="line"> [Downloads](downloads.md): follow, cancel and retry downloads.
* <img src="../.gitbook/assets/icons/restart.png" alt="" data-size="line"> [Apply & Restart](apply-and-restart.md): restart the game with your profile's mods.
* <img src="../.gitbook/assets/icons/profiles.png" alt="" data-size="line"> [Start in your profile](start-in-your-profile.md): have Steam's **Play** button start the game in your profile (Steam version, on Windows, Linux and the Steam Deck), or let DewDrop offer a restart into it.
* <img src="../.gitbook/assets/icons/gear.png" alt="" data-size="line"> [Settings](settings.md): the options on the **Account** tab.

{% hint style="info" %}
New to profiles and restarting? Read [How launching works](../getting-started/launching.md) first. It explains why mods you turned off can still load when you start the game from a shortcut, and how **Apply & Restart** fixes that.
{% endhint %}

Playing on a Steam Deck? The menu works in Game Mode. [DewDrop on the Steam Deck](../getting-started/steam-deck.md) covers the setup and what's different there.
